# C++ Sorting & Array Algorithms 🚀

This is my first project on GitHub! 
This code has 11 basic sorting and array algorithms in C++. 

## What is inside? 📦

Here is the list of algorithms + Time Complexity:

1. **Bubble Sort** → O(n²)
2. **Selection Sort** → O(n²)
3. **Insertion Sort** → O(n²)
4. **Quick Sort** → O(n log n)
5. **Merge Sort** → O(n log n)
6. **Counting Sort** → O(n + k)
7. **Quick Select** → Find K-th largest = O(n)
8. **Min-Heap** → Find K-th largest = O(n log k)
9. **Merge Count** → Count inversions = O(n log n)
10. **Odd & Even** → Odd first, even later = O(n)
11. **Multi-Criteria Sort** → Sort `Student` objects by Grade, Score, and Name.

## How to run 💻

+ **Step 1:** Open your terminal.
+ **Step 2:** Compile the code → Type `g++ main.cpp -o main`
+ **Step 3:** Run the program → Type `./main`
